Обычное окно, нижняя навигация в отдельной области. Фото FluxoGram отображается при наличии разрешённого photo_url. При отсутствии можно выбрать локальное фото, оно не отправляется на сервер и не синхронизируется между устройствами. Имя берётся из данных запуска и не является проверенной серверной авторизацией. Коллекции и баллы локальные, без покупок, ставок и переводов.
