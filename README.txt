MARKT 16.0

Публикация: загрузить содержимое архива в корень существующего репозитория GitHub Pages, включая assets.
Обычное окно Mini App; полноэкранный режим не запрашивается. Нижнее меню занимает отдельную строку, прокручивается только контент. Нажатие на логотип открывает дополнительное меню разделов.
Аватар: Профиль → Установить аватар пользователя. Фото обрезается до квадрата и сохраняется локально для текущего профиля. При удалении используется фото клиента, если оно доступно, иначе первая буква имени. Фото не отправляется на сервер и не меняет профиль FluxoGram. Имя берётся из данных запуска Mini App, без серверной проверки. Баллы и коллекция локальные, без покупок или переводов.
